# WinUI-BBS 1.0.0

1.0.0 正式版加入帖子版权声明、回复通知与屏蔽、举报处理，并改进列表性能、后台权限刷新和会话恢复。

## 讨论与内容管理

- 发帖时可选择 CC0、六种 Creative Commons 4.0 许可、版权所有声明或“不适用”。声明随草稿保存，在正文后单独显示，审核、回收站和恢复后继续保留。
- “站内通知”新增“回复我的”和“屏蔽管理”。回复可跳转到对应主楼或楼中楼；回复通知和屏蔽记录按每页 20 条显示，可按用户名屏蔽或撤销屏蔽。
- 帖子、回复和用户资料可提交举报。拥有 `posts.manage` 的管理员在“举报处理”中隐藏、删除内容、封禁用户或标记不处理；首位管理员、自己及最后一位可管理用户组的管理员继续受到封禁保护。
- 帖子作者可以举报自己帖子下的他人回复。删除被举报回复沿用回复管理规则：保留仍有子回复的主楼占位，通知受影响作者，并记录删除与举报处理操作。

## 性能与权限

- 个人和公开收藏夹按站点每页帖子数分页；“我的图片”按每页 50 张显示，支持页码跳转、Enter、刷新和浏览器返回。旧版不带 `page` 的 API 调用保留原返回格式。
- 首页和用户后台减少列表、图标包装，并逐帧挂载帖子；日期格式器复用，摘要达到显示长度后停止处理后续段落。收藏和用户空间复用数据库维护的回复总数。
- 管理后台进入页面前刷新权限，停留期间每 30 秒及重新激活页面时复核。权限撤销、成员资格到期或封禁后，相关导航和已打开页面会移除；API 继续对每次请求独立鉴权。
- 修复旧请求覆盖新筛选结果、退出后旧请求恢复身份、过期登录阻止社区加载、通知页签切换及举报分页文案等问题。浅色主题恢复默认后，强调按钮与选中圆点保持正确前景色。

本轮验证覆盖 174 项 API 集成测试、八种单一管理权限对全部 20 个后台页面的 160 次访问，以及收藏、图库、键盘操作和窄屏布局。开发模式仍偶发上游 WinUI 的 `ResizeObserver loop` 提示；最终独立浏览器操作流程无运行或控制台警告、错误。

## 从 0.5.0 升级

1. 备份 PostgreSQL、完整 `apps/api/data/`、对象存储和原部署配置，保留 `MAIL_ENCRYPTION_KEY` / `STORAGE_ENCRYPTION_KEY`。
2. 已有一键安装实例可在“站点设置 → 系统更新”选择 Releases 并升级；手动部署使用附件 `winui-bbs.tar.gz`。源码部署更新后执行 `npm ci`、`npm run check`、`npm run build`，再重启服务。
3. API 启动时自动应用迁移 030–032：帖子版权、回复通知与举报、收藏夹及个人图片排序索引。创建索引会暂时阻塞相关表写入，大数据库应安排维护时段。从更早版本升级时，也会应用尚未执行的迁移。
4. 保留完整前端 `dist` 及 `.br` / `.gz` 文件。历史帖子默认不附加版权声明；现有账号、帖子、图片、TOTP 与 Turnstile 配置继续沿用。

回退程序前确认数据库兼容性；需要恢复数据库时先停机，再配套恢复升级前备份。任何回退版本都应支持当前密码格式和已启用的 TOTP。安装与更新步骤见[发布与恢复指南](https://github.com/tzhx12/WinUI-BBS/blob/v1.0.0/docs/releases.md)，完整功能见[使用与配置](https://github.com/tzhx12/WinUI-BBS/blob/v1.0.0/docs/configuration.md)。
